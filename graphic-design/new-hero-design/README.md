# New Hero Graphic Design

This folder contains approved redesign candidates for the brighter WTK visual direction.

These assets are **not production assets yet**.

Do not replace or rewire the current files under `public/hero-*` until the complete hero/card redesign set is reviewed and approved together.

## Direction

- brighter ancient-Chinese visual style
- clearer character silhouettes and costumes
- masked / obscured faces where approved
- hero-focused artwork without card UI baked into the image
- coordinated faction colour identity

## Current candidates

- Liu Bei — bright Shu green / ivory / gold, masked, facing direction intentionally different from Cao Cao
